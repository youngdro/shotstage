# shotstage API reference

_Generated by `shotstage commands --markdown` from the command catalog; do not edit by hand._

Every command below is available, with the same parameters and results, from:

| Entry point | How to call `camera.frame` |
| --- | --- |
| Browser | `editor.dispatch("camera.frame", params)` or `await editor.call("camera.frame", params)` |
| CLI | `shotstage run camera.frame '{...}' -s shot.json` (or `batch`, `serve`) |
| MCP | tool `camera_frame` (or `command_run` with `{"command": "camera.frame", "params": {...}}`) |

Units: metres, degrees, frames; +Y up, the ground is y = 0, object fronts face +Z, cameras look down -Z. Parameters are validated: a missing or unknown field, a wrong type or an out-of-range value returns `invalid_params` and leaves the scene unchanged. Commands marked _changes the scene_ are one undo step each (a batch is one step for all of its commands).

**Host commands** need more than the scene: _gpu_ (rendering), _files_ (reading / writing files: CLI and MCP; the desktop editor too), _view_ (the editor's selection and playhead; the CLI and MCP server keep one per session). In the browser the rendering ones resolve asynchronously through `editor.call`.
